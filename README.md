## 建议阅读顺序

1. 先读 [学习指南](MCM_A_备赛学习指南.md) 的第一章，建立“题目—模型”的全局地图；再按模型章节逐个吃透。
2. 读 [历年分析报告](MCM_A_2020-2026_历年分析报告.md) 的第一章，逐年看题意、问题拆解与建模思路。
3. 对某一年的论文，按报告第三章的顺序读：先逐篇分析，再看同年横向对比，最后看跨年归纳。
4. 读论文时对照原 PDF，重点看：摘要如何组织、模型链如何连接、结果用什么证据验证、建议如何落到目标受众。
